# 数据字典页的格式

`datasets/<数据源>/<表名>.md`，一张表一页。只写你从表结构和查询结果里确认过的内容；猜测的标"（未确认）"。

    ---
    type: dataset
    source: <数据源名>
    table: <表名>
    description: 一句话：这张表是什么数据、什么粒度；什么时候该用它
    grain: 每个 <标的> 每个 <交易日> 一行
    date_range: YYYY-MM-DD ~ YYYY-MM-DD
    checked: YYYY-MM-DD          # 上次核对的日期
    ---
    # <表名>

    ## 用途
    这张表回答什么问题；与相近的表有什么区别、何时该用哪张。

    ## 关键字段
    | 字段 | 类型 | 含义与单位 |
    |---|---|---|

    只列分析时用得到的字段，不用把全部字段抄一遍。

    ## 已知的坑
    重复行、空值、单位、复权、停牌日有没有行、历史上口径的变化。每条写明是怎么发现的。

    ## 常用查询
    一两条确认能跑的查询，放在 sql 代码块里。

- 页面里的 sql 代码块同样必须是本次任务里原样执行过的。
- `description` 不超过 200 字，它会出现在数据字典目录里。
- `datasets/_index.md` 由引擎生成，不要改。
- 更新已有页面时，保留别人写的内容，只改你确认有变化的部分，并更新 `checked`。
