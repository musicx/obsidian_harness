# 把话说清楚

读者没有参与过程，只读这一篇，而且时间不多。每句话都要给他一点他还不知道的东西。

## 写的时候

- **先说结论。** 第一段就回答读者最想知道的那件事，依据和过程放后面。
- **一句话只说一件事**，主语明确，用主动句。能用具体的数字、日期、名字，就不用"大幅""近期""相关方"。
- **写给外人看。** 不用过程中自己起的简称和代号；第一次出现的术语用一句话解释，或链接到它的知识页。
- **篇幅跟着内容走。** 没有内容的小节删掉，不要写"暂无"撑结构。并列的三条以上用列表，需要对比的用表格，其余用段落。
- **不确定就说不确定**，并说明缺什么；不要用含糊的措辞盖过去。
- 用户提供了写作风格说明（`practice/写作风格.md`）时，先读它，以它为准。

## 交稿前自查

发现一处就改一处；但只是偶尔出现一次的修辞不算毛病，不要为了"去 AI 味"把正常的句子改僵。

| 毛病 | 样子 | 改法 |
|---|---|---|
| 摆架势不说事 | "这不仅仅是 A，更是 B""值得注意的是""让我们来看看" | 直接说 B 是什么 |
| 结尾升华 | 段末一句"这标志着……的重要一步""总之，……至关重要" | 删掉；要点前面已经说过 |
| 凑三个 | 每个列举都是三项、三个排比 | 有几项写几项 |
| 空泛的重要性 | "关键""核心""深刻""全面""赋能""抓手" | 换成它具体造成了什么 |
| 借来的权威 | "业界普遍认为""研究表明"却没有出处 | 给出处，或删掉 |
| 装饰性格式 | 每条开头加粗一个标签、小标题只是把首句重复一遍、满篇破折号 | 去掉加粗；小标题说内容不说类别 |
| 重复读者已知 | 开头复述一遍问题或背景 | 直接答 |
| 聊天残留 | "希望对你有帮助""如需进一步……""以下是……" | 删掉 |
| 写文档自己 | "本报告将从三个方面……""下文将介绍" | 删掉，直接写那三个方面 |

## 底线

改文字不改事实：任何事实、数字、日期、名字、引文、出处链接，改写前后必须一致；不能为了通顺删掉限定条件（"在样本量足够时""截至 11 月"）。拿不准一处修改是否改变了意思，就不改。
